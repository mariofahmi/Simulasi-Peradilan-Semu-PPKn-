# 🏛️ Simulator Peradilan Semu — Prodi PPKn UNIROW Tuban

Media Pembelajaran Interaktif Praktik Peradilan Semu *(Moot Court)* & Evaluasi Ujian Berbasis Web untuk Mahasiswa Program Studi Pendidikan Pancasila dan Kewarganegaraan (PPKn) Universitas PGRI Ronggolawe (UNIROW) Tuban.

## ✨ Fitur Utama Aplikasi

1. **⚖️ 4 Kasus Sidang Nyata (12 Skenario Peran):**
   * **Kasus 01 (Tipikor):** Dugaan Korupsi Pengadaan Alsintan Dana Desa (*UU No. 31/1999 jo. UU No. 20/2001*).
   * **Kasus 02 (KDRT):** Kekerasan Psikis & Ekonomi dalam Rumah Tangga (*UU No. 23/2004*).
   * **Kasus 03 (UU ITE):** Kebebasan Berekspresi & Kritik Anggaran di Media Sosial (*Pasal 28 UUD 1945 & UU ITE 2024*).
   * **Kasus 04 (Agraria):** Sengketa Hak Ulayat Masyarakat Adat vs Korporasi Sawit (*UUPA No. 5/1960 & Pasal 18B UUD 1945*).
   * Pilihan peran: **Ketua Majelis Hakim**, **Jaksa Penuntut Umum (JPU)**, dan **Penasihat Hukum**.

2. **📝 Bank Soal Ujian Komprehensif (50 Soal Acak):**
   * Mencakup Bab 1 s/d Bab 7 buku rujukan.
   * Pengacakan otomatis soal dan pilihan ganda (A, B, C, D) dengan algoritma Fisher-Yates.
   * Skema penilaian: **1 Soal Benar = 2 Poin (Total Skor 100)**.
   * Dilengkapi pembahasan & dasar hukum instan.

3. **👤 Sistem Identitas Otomatis:**
   * Form pengisian Nama Lengkap & NPM mahasiswa sebelum pengerjaan.
   * Nama dan NPM otomatis tertera pada kolom tanda tangan dokumen pengesahan.

4. **🎵 Musik Motivasi & Smart Focus Mode:**
   * Musik instrumental inspiratif berputar di dashboard dan menu.
   * **Otomatis menjeda (*auto-pause*)** saat mahasiswa memasuki persidangan atau pengerjaan soal.

5. **📖 Glosarium Hukum & PPKn (48 Istilah):**
   * Kamus istilah hukum acara (A - U) dengan pencarian instan dan filter navigasi alfabet.

6. **🖨️ Rapor & Sertifikat Siap Cetak (Pas 1 Halaman A4):**
   * Kop Surat resmi UNIROW Tuban.
   * Rubrik evaluasi Bab 6 dan sertifikat kelulusan ujian.
   * Dikalibrasi anti-terpotong untuk format cetak / simpan PDF.

## 🚀 Menjalankan Aplikasi

Aplikasi ini dibangun menggunakan **Single-Page Vanilla Web Architecture (HTML5, CSS3, JavaScript modern)** murni tanpa ketergantungan library eksternal.

Cukup buka file `index.html` langsung di browser apapun (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
